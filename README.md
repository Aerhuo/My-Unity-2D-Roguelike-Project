# 项目技术介绍

## 1. 实体架构与组件管理
- **面向接口的程序设计**：将实体拆分为 IEntity、 IDamageable、IAttacker、IUseable 等独立接口，解耦具体业务逻辑。
- **LRU组件缓存池**：摒弃高频的 GetComponent，底层通过一维数组和游标实现的双向链表（_l, _r），自定义了一套带有 LRU 特性的轻量级 Service Locator，实现组件的大量访问情况下的性能提升，最坏情况下仅比 TryGetComponent 多进行二十次数组遍历，得益于现代 CPU 的缓存命中率优化，额外开销几乎可以忽略。
- **设计模式**：大量使用观察者模式（基于 Action 的事件分发，如 OnTakeDamage、OnTurnEnd）与单例模式（各大 Manager 管理器）。

## 2. 寻路与AI系统
- **混合寻路机制**：全局距离场：利用 PathTarget 实时更新目标位置的广度优先搜索距离。局部动态 A*：通过优先队列实现 A*，并直接将 BFS 距离直接作为启发函数，配合 extraCost 处理动态障碍物（如其他实体），解决单一路点拥堵问题，进一步优化了 A* 的性能，并且可以复用距离场完成其它逻辑。
- **状态机 AI**：基于视野系统实现怪物 Wander、Chase、Away 状态切换。

## 3. 回合制与时序控制
- **能量速度系统**：基于 ITurnTaker 的能量积攒与消耗决定行动权，支持不同速度单位的差异化行动频率。
- **逻辑与表现分离**：通过事件队列 turnEventQueue 压入动作，配合 AnimationComponent 的协程队列形成“动画锁”，保证底层数据瞬间结算后，表现层按序播放完毕再推进下一回合。

## 4. 视野与战争迷雾
- **FOV 检测**：基于 Bresenham 算法实现无缝的圆形视线投射。
- **三态迷雾管理**：将地图分层为 Unexplored、Explored、Visible，配合 Tilemap 进行动态图块刷新。

## 5. 地图与空间数据
- **程序化生成**：基于元胞自动机生成多层联通（通过 MST + A* 实现连通）的随机地牢，并采用策略模式方便之后实现多种地图生成方案。
- **空间划分**：使用二维数组 GridCell[,] 记录单格内的所有实体。房间索引池：维护 AvailableTilesByRoom 和索引数组，以 O(1) 复杂度实现空地校验与实体随机安全生成。
